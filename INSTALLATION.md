# Guide d'installation — GitHub Pages

## Étape 1 — Créer le dépôt GitHub

1. Connecte-toi sur **github.com**
2. Clique sur **"New repository"** (bouton vert)
3. Nomme le dépôt : `haccp-audit`
4. Laisse-le **Public** (obligatoire pour GitHub Pages gratuit)
5. Clique **"Create repository"**

---

## Étape 2 — Uploader les fichiers

1. Dans le dépôt vide, clique **"uploading an existing file"**
2. Glisse-dépose ces 5 fichiers :
   - `index.html`
   - `README.md`
   - `INSTALLATION.md`
   - `LICENSE`
   - `.gitignore`
3. En bas, clique **"Commit changes"**

---

## Étape 3 — Activer GitHub Pages

1. Va dans **Settings** (onglet en haut du dépôt)
2. Dans le menu gauche, clique **"Pages"**
3. Sous **"Source"**, sélectionne **"Deploy from a branch"**
4. Branche : **main** — Dossier : **/ (root)**
5. Clique **"Save"**

---

## Étape 4 — Accéder à l'application

Après 1 à 2 minutes, ton application est accessible sur :

```
https://[ton-nom-github].github.io/haccp-audit/
```

Exemple : `https://mounir.github.io/haccp-audit/`

---

## Mettre à jour l'application

Pour mettre à jour avec une nouvelle version :

1. Va sur ton dépôt GitHub
2. Clique sur `index.html`
3. Clique sur l'icône **crayon** (Edit)
4. Sélectionne tout le contenu et remplace par le nouveau fichier
5. Clique **"Commit changes"**

Ou plus simplement :
1. Clique **"Add file"** → **"Upload files"**
2. Glisse le nouveau `index.html`
3. Confirme le remplacement
4. Clique **"Commit changes"**

---

## Utilisation hors ligne (sans internet)

Le fichier `index.html` peut aussi être ouvert **directement** depuis ton PC ou téléphone :

- **PC** : Double-clic sur `index.html` → s'ouvre dans Chrome ou Edge
- **iPhone** : Enregistrer dans Fichiers → ouvrir avec Safari
- **Android** : Télécharger et ouvrir avec Chrome

⚠️ Sur Firefox, ouvrir un fichier HTML local peut bloquer certaines fonctions. Utiliser Chrome ou Edge de préférence.
